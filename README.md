#  BUILD4BETTER – Hackathon Project

##  About the Project

This repository contains a Flutter-based mobile application developed during the **BUILD4BETTER Hackathon**.

The project was developed collaboratively with my teammates. We worked together to turn an idea into a mobile application, focusing on application development, user interface design, problem-solving, and implementing the planned features.

Participating in this hackathon gave us an opportunity to apply our technical knowledge, explore new ideas, and gain practical experience working as a development team.
